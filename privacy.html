Privacy Policy

Last Updated: October 31, 2026

This Privacy Policy explains what information the E7 Fribbels & Smilegate Update Bot ("the Bot") collects, how it is stored, and how it is used when you interact with the Bot on Discord.

1. Information We Collect and Store

The Bot only stores data that is explicitly provided by users or server administrators through slash commands:

  • Server Update Feed Subscriptions (/feed subscribe): Stores your Discord Server ID (guild_id), Target Channel ID (channel_id), optional Role ID for pings (role_mention_id), and the subscribed RSS/feed URL so the Bot knows where to deliver update announcements.
  • Shared Character Builds (/build share): Stores your Discord User ID (user_id), Display Name, Server ID, and the Epic Seven hero build details you submit (hero name, sets, artifact, in-game stats, optional notes, and optional screenshot attachment URL).
  • Shared Battle Replays (/replay share): Stores your Discord User ID (user_id), Display Name, Server ID, match metadata (title, mode, win/loss result, rank tier, hero drafts, MVP hero, notes), and the media/video URL you attach or provide.

2. Information We Do NOT Collect

  • We do not log, store, or read private messages or general chat history in your server.
  • We do not collect personal identifying information outside of public Discord identifiers (User ID, Display Name, Guild ID, Channel ID) required for command functionality.
  • We do not sell, rent, or share any stored data with third parties or advertisers.

3. Data Retention & Deletion

Data submitted via /build share, /replay share, and /feed subscribe is stored in the Bot's local SQLite database for as long as needed to provide those features:

  • Server administrators can remove update feed subscriptions at any time using /feed unsubscribe.
  • Users can overwrite their saved hero build at any time by running /build share for that hero, or request complete removal of their saved builds/replays by contacting the Bot administrator.

4. Third-Party Services

When you run commands like /fribbels or /feed, the Bot makes outbound requests to public endpoints (such as the Fribbels Epic Seven Hero Library API and Smilegate/Steam news feeds) to retrieve game data. No personal Discord user data is transmitted to those services.

5. Contact & Data Removal Requests

If you have any questions about this Privacy Policy or wish to request deletion of your stored builds or replays, please contact the Bot owner via Discord in the support server where the Bot is hosted.
